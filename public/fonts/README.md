# PDF font

Noto Sans SC from Google Fonts, licensed under the SIL Open Font License (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

The bundled TTF is a static weight-500 instance of NotoSansSC[wght].ttf, created with fonttools varLib.instancer. Its glyph data uses 4-byte alignment for compatible PDF font subsetting. It is served locally for bilingual PDF statements; no external font service is used.

## UI fonts

Inter-Latin.woff2 and JetBrainsMono-Latin.woff2 are self-hosted variable-weight (400–700) Latin fonts from Google Fonts. Their SIL Open Font Licenses are included as Inter-OFL.txt and JetBrainsMono-OFL.txt. Source families: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/google/fonts/tree/main/ofl/jetbrainsmono. The UI makes no runtime request to Google Fonts; Chinese text uses the device's system fonts.
