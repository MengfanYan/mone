# 数据治理与操作清单

2026-10-15。此文描述当前代码边界及发布前需负责人确认的运营项目；建议期限来自 [产品策略](PRODUCT_STRATEGY.md)，尚未对客户承诺。

| 数据 | 当前代码处理 | 需要配置/验证 |
|---|---|---|
| 财务记录/报表 | 本地SQLite或云端租户PG；只从确认事件计算；历史快照不静默覆盖 | 云存储/备份静态加密、访问、地区和恢复验证 |
| Auth | 托管认证；服务器Cookie、JWT校验、邀请、MFA和设备撤销；JWT不写浏览器localStorage | 邮件、MFA丢失恢复、管理员MFA、限流/风险策略 |
| 上传原件 | 云端私有隔离，未经验证不可下载；5MB限制；元数据有24h到期 | 扫描/解析沙箱和定时清扫未启用；到期不是物理删除；不应输入真实资料 |
| 文本资料库 | 私人settings中保存文本，按分析授权读取，不自动发送模型 | 原件/提取文字保留策略、对象和索引删除传播 |
| 任务/个人规则/反馈 | 属于本人空间；规则只用于未来未分类草稿；反馈训练授权固定false | 保留期、来源撤销后的重评与用户支持 |
| 外部模型 | 云端入口关闭；本地已有逐次载荷确认 | 供应商/数据类别/地域/期限授权、预算、CDR数据默认禁止外发 |
| 日志 | 仅服务端生成trace ID、固定路由分组、方法、状态、耗时；不记请求正文、金额、商户、令牌和完整URL | 平台日志留存、支持访问和告警；不将私有内容送营销分析 |
| 删除控制 | 第二项目中的签名租户散列/代次/请求散列，财务恢复之外保留 | 访问审计、留存、不可丢失的旧验证密钥、真实服务联调 |
| 下载件 | 浏览器JSON/CSV/PDF或AES-GCM加密备份 | 由用户管理；服务端删除不能清除已下载副本 |

## 导出、删除与恢复

导出、撤回用途、退出设备、删除应用数据、删除Auth账号、取消未来订阅是独立动作。当前应用数据删除覆盖金融表、个人规则、反馈、任务和挑战；对象必须先移除，身份账号清除流程尚待接入。不得宣称已经删除供应商账号或客户自行保存的备份。

恢复必须在未公开的隔离目标中执行，保留独立删除记录和全部历史验证密钥。先恢复数据库/对象，执行删除代次围栏、关闭原用途和任务、要求重新登录，再核验后对外开放。运行角色不能执行管理恢复。当前合成测试证明数据库围栏行为；真实对象字节、云备份、密钥可用性及恢复时间尚待演练。

## 发布与事故操作

发布记录填写：源码版本/哈希、功能/市场开关、供应商与处理区域、保留规则、模型/工具/计算版本、证据链接、回滚方式、负责人及联系方式。没有相应证据的字段保持待验收。真实数据试用需P0完整验收；公开收费另需首发P1、价格和政策。

事故流程按职责执行：停止相关外发/写入 → 限制受影响访问 → 保存最小证据 → 明确受影响数据/用户/供应商 → 由负责人评估通知与恢复 → 复核删除/授权围栏 → 记录原因和纠正措施。不要将账本正文复制到工单或公开日志。通知时限、法定保留与金融建议范围由实际适用主体及专业顾问确认，本代码不作合规认证。

负责人、支持邮箱、事故联系人、供应商合同、保留期限与演练日期尚未由项目方提供。自动预检查不会生成这些人的签署，也不会把模板变成已完成的演练。
