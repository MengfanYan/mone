# ADR 004 · 免费优先的云端安全账本基础

日期：2026-10-15。状态：源码已实施、合成验证；外部部署待配置。

依据：[PRODUCT_STRATEGY](../PRODUCT_STRATEGY.md) 第10–13、17节，以及用户“优先选择免费的主流平台”“收费保持关闭”的决定。云端 SaaS 成为后续产品主线；本地版保留为开发、迁移和用户可运行的既有交付。

采用 Supabase Auth/PostgreSQL/Storage，财务主区选择悉尼；第二个免费项目保留独立删除控制记录。使用 FastAPI/Uvicorn 外壳和事务化 PostgreSQL 适配器复用已有领域逻辑，Next.js BFF 使用服务端 Supabase SSR Cookie。前端不直接持有管理 key，API 不接收客户端身份归属。

每笔事务设置本次身份、角色、租户及命名空间；数据库 FORCE RLS、复合外键和精确分录约束作为第二层保护。移植仅转换固定、代码内的 SQL 语句；客户端和模型没有 SQL 工具。迁移/恢复角色与运行角色分离，身份服务签名验证和本地会话撤销分别执行。

Render Free 单容器仅作为开发部署参考。它减少初期托管组件，但计算区在新加坡且没有进程失陷后的强隔离；免费休眠和资源限制不满足尚未演练的生产目标。将来可迁到澳洲容器平台，保留数据库及业务契约。

没有引入 LangChain、LangGraph、外部向量库、Kubernetes 或多 Agent。外部模型、银行、Stripe 与个性化产品建议保持关闭。个人规则仅影响未来未分类草稿，反馈不进入全局训练。

取舍和后续：公众注册需 Auth 配置、邀请/开放策略和条款；真实数据需恢复、密钥、对象、删除及运营证据。只读规则分析与文件隔离接收可以先验证，云端 OCR 在隔离 Worker 配置前拒绝执行。当前不以原型通过冒充 P0/P1 全部完成；矩阵见 [策略实施状态](../STRATEGY_IMPLEMENTATION.md)。
