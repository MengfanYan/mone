# Product demo · 产品演示

Demo 是独立的浏览器演示沙箱。它复用当前产品的八个模块和中英文界面，使用手动编排的合成场景；不需要 Python、访问码、API 密钥、Tesseract、银行连接或外部网络服务。项目统一使用 Node.js 22+ 和浏览器，`.nvmrc` 固定已验证的 Node 22.23.3；安装和运行步骤见 [RUNNING](RUNNING.md)。

2026-10-16更新：统一暗色界面与首页站内通知。新场景可演示预算超额、工资记账、两次保存价格的下跌、已读保存及来源跳转；手机优先显示通知，助手图标位于顶栏。已有浏览器场景如缺少价格示例，使用 **Demo scenario & reset → Reset demo** 加载新预设。[设计与通知规则](UI_NOTIFICATIONS.md)。

```bash
npm run demo
```

打开 **http://localhost:3001**，即可直接进入填好数据的工作台。默认英文，**EN / 中文** 切换并记住语言偏好。演示数据以 **2026 年 9 月** 为默认观察期，同时提供 7–9 月账本。无需修改 `.env.local`。

客户演示时也可使用优化后的版本：

```bash
npm run demo:build
npm run demo:start
```

`DEMO_PORT=3100 npm run demo` 可更换端口。端口已占用时启动器会给出提示；Ctrl+C 关闭演示服务。首次安装依赖可使用 `npm ci`，依赖安装本身通常需要网络。

## 可以展示什么

| 模块 | 预设内容与可演示交互 |
|---|---|
| 财务概览 | 三个月收支、按周资金流、预算使用、四个账户、AUD/USD 分开展示、关注事项 |
| 账本与导入 | 54 条已确认事件、3 条待确认草稿、重复候选、修改/确认/拒绝、冲正；手工、CSV 和凭证三种入口 |
| 预算与目标 | 月度收支假设、预算超限、应急金与旅行目标、现金压力情景；修改后预览确认，结果在浏览器内更新 |
| 投资记录 | 稳定条目/估值历史、未知成本和单点；追加估值/收益事件/修订/归档；独立 CNY 本金分红案例 |
| 月度账单 | 两个月固定快照、中英文 PDF 直接预览、翻页、缩放与下载；确认新记录或修改规划后可生成新版本，旧版保持不变 |
| 分析助手 | 收支、预算、现金压力、持仓和市场五类预设脚本；资金操作请求展示产品边界，不执行交易 |
| 隐私与授权 | 两个模拟用途开关、撤回后的停止计算、演示 JSON 导出、清除演示内容、重新进入或重置 |

建议顺序：概览 → 待确认草稿 → 预算目标 → 持仓 → 月报 → 分析 → 隐私。在 CSV 页点击 **Fill sample CSV / 填入演示CSV**，在凭证页点击 **Fill sample receipt / 填入演示凭证**，即可展示完整导入流程。

市场指数是**虚构预设**，不是 BLS 数据或实时价格；刷新只恢复本地样例。新凭证入口解析支持的类型化文本并明确标为模拟识别；可填入编排的小票/流水/基金样例。任意图片会被拒绝，避免把无关预设当成图片识别结果。分析解释来自预设脚本，涉及金额时读取当前演示账本的本地计算结果，不调用 LLM。正式版未提供的支付、交易、云处理和共享并未因此变成真实能力。

## 重置与数据隔离

页面顶部展开 **Demo scenarios & reset / 演示场景与重置**，或在演示登录页，均有 **Reset demo / 重置演示**。它恢复原始场景、默认月份和初始草稿，便于下一次客户演示；语言偏好保留。

修改只写入当前来源下的浏览器 `localStorage` 键 **`zhizhang.product-demo.v1`**。刷新保留修改。浏览器禁止存储时自动改用内存，页面明确说明关闭后修改会消失。清除或重置只处理该演示空间，不清理其他浏览器数据、正式 SQLite 数据库或正式会话。不同浏览器/来源有各自的演示空间。

PDF 和 JSON 下载都标记为 MOCK；JSON 文件名是 `wallet-demo-export.json`。下载的文件仍属于用户自行管理的本地文件。

浏览器演示存储和下载文件未加密。客户展示请只输入合成资料；不要输入真实姓名、账户、账单或其他私人金融信息。正式版的数据流与安全存储要求见 [SECURITY.md](SECURITY.md)。

## 与正式版并存

| | 正式接口模式 | 独立 Demo 模式 |
|---|---|---|
| 开发命令 | `npm run dev` | `npm run demo` |
| 优化构建/启动 | `npm run build` / `npm start` | `npm run demo:build` / `npm run demo:start` |
| 默认端口 | 3000，Python API 8765 | 3001，无 Python API |
| 构建目录 | `.next` | `.next-demo` |
| 数据 | `.local-data/wallet.sqlite3` | 浏览器独立演示键 |
| 工作台数据来源 | 保留的 `/api/*` → Python 接口 | 浏览器预设适配器，没有 API 请求 |

正式版登录页也提供 **Explore product demo / 查看产品演示**，通向 `/demo`。该页面使用同一个隔离的浏览器沙箱。正式模式中的 API 继续正常工作；独立 Demo 服务中的 `/api/*` 返回 `DEMO_API_DISABLED`，不会转发到真实后端。

当前目录没有 Git 仓库，因此没有创建分支。两种模式在同一代码库中共享 UI，以入口、数据适配器、启动命令、端口和构建目录区分。以后如采用 `main` / `demo` 分支，仍应保留这组边界；无需复制或删除正式接口。

## 检查与维护

```bash
npm run test:demo       # 本地金额、模拟交互、快照、隔离与存储降级
npm run lint
npm run demo:build
npm run test:e2e:demo   # 先构建；桌面/移动端、双语、禁用 API/外网、断网交互
npm run check          # 正式业务测试、演示逻辑、lint 和两种构建
npm run test:e2e       # 正式 API 流程与 /demo 不影响正式账本的隔离测试
```

浏览器测试可使用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指向已有 Chromium；也可安装 Playwright Chromium。所有浏览器测试使用隔离的数据，不打开个人数据库。

预设场景在 [`lib/demo/preset.mjs`](../lib/demo/preset.mjs)，本地模拟接口在 [`lib/demo/client.mjs`](../lib/demo/client.mjs)，精确金额计算在 [`lib/demo/calculations.mjs`](../lib/demo/calculations.mjs)。这些模拟实现不是正式财务服务或认证控制。新增需要网络的功能时，同时添加对应预设、demo 标识和无网络测试；不要让 demo 静默回退到正式 API。

## UX 1.0 演示路径（2026-10-15）

1. 在文本入口输入 `add Customer wallet account 0 CNY`，核对并确认建立本地演示账户。
2. 输入 `我今天买咖啡花了7dollars，兼职赚了200元。`，逐卡批准 AUD/CNY 与账户。点编辑可修正金额；候选不入账。
3. 保存选中草稿或预览并确认，查看同币种摘要。用 `change just 咖啡 to 6.50` 或结果卡编辑进行更正，历史保留。含糊匹配必须选择。
4. 凭证模式选择 Bank statement / Investment valuation & gain，填入模拟样例。转账需补对方账户；基金的今日收益与累计收益分别保存，浮盈不进工资。
5. 投资页选 CNY，查看 **Capital & distributions example**：真实合成观察点累计收益 `0/100/120/220/215`，增投 500 不当成盈利。切换未实现/报告/净收益/市值和时间范围，查看证据数据。
6. 预算关系图、费用分类或按周记录可下钻。传统编辑器按需打开；手机底部 More 内有规划/月报/授权。月报保持真实 PDF。

Demo 记录日期明确模拟为2026-09-30，正式模式按真实用户时区。演示存储内部experience version 2保留原编辑/清除状态，重置恢复历史种子；查询、确认、历史、导出和删除不请求正式API。本轮20项Node逻辑、21项实际浏览器检查通过，覆盖禁API/外网、断网、八个宽度/横屏/短窗口、双语、PDF、下钻和估值修订/归档。11项手机重复矩阵有意跳过，对应桌面矩阵已执行；见[UX验证](UX_VALIDATION.md)。


## 六图终端界面与新增演示流程

现在使用深色终端界面，默认英文、支持中文。手机 More 包含规划、月报、隐私和 Settings；Cmd/Ctrl+K可搜索全部模块。

新增可操作流程：资产分布和配置权重工作表、历史单位价格风险实验（明确合成样例）、可编辑蒙特卡洛规划、文字框来源定位、凭证PDF本地文本提取、交易筛选/排序/选中CSV导出、屏幕遮罩、加密备份及验证、本地资料检索和手写模型解释预设。模型预览会明确显示 OFFLINE / NO NETWORK；不是实际模型结果。新配置和本地资料仍只存 `zhizhang.product-demo.v1`，正式API与SQLite不受影响；全量导出/删除/重置覆盖它们。密码只保留在内存。

任意扫描图仍不在Demo中运行Tesseract；使用预设识别文本，或上传可选中文字的PDF做本地提取。正式版另外支持单页扫描PDF转本地OCR。月报继续直接预览真实PDF，不改成Markdown。普通CSV/JSON/PDF未加密；选择加密备份才得到 AES-GCM 文件。规划与风险实验在页面内存中运行，未写入实际账本，不构成投资预测。
