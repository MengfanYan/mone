# 统一暗色界面与站内通知

实施日期：2026-10-16（Australia/Sydney）。参考用户提供的[设计文档](https://docs.google.com/document/d/1vui69964o-XeQBrXaFc0R7X5ze4BRQXLaNO0ld1V9Rw/edit)。文档通过文本导出读取；采用其设计规范，原型中的模拟金额、弹出提示、CDN脚本与隐私模糊逻辑不替代产品业务实现。

## 视觉与布局

| 规范 | 当前实现 |
|---|---|
| 三层空间 | 画布`#08090A`、导航`#101216`、卡片`#161920`、悬停`#1C202B`；靛蓝强调，翠绿/玫红/琥珀表达不同状态 |
| 材质 | 12px卡片、细边框、顶部内高光、重点卡片微光；普通内容卡保持可读背景，避免所有模块抢占视觉重心 |
| 排版 | Inter正文、JetBrains Mono金融数字，400–700可变字重，本地WOFF2与OFL许可；中文使用系统字体，运行时不请求Google Fonts |
| 交互 | 模块指令面板、表格悬停操作栏、按钮按压、滑块微光、有限次数状态脉冲；减少动态效果偏好下关闭动画 |
| 可达性 | 长投资卡片保留静止位置，避免嵌套按钮随悬停漂移；控件滚动留出固定顶栏/底栏空间 |
| 响应式 | 共用设计系统覆盖八模块、登录/恢复、弹窗和云设置。手机通知优先于指标卡；手机助手图标归入顶栏，桌面助手预留独立右侧边距 |

统一样式入口是`app/design-system.css`，由根布局加载。保留已有模块特定的数据布局、PDF预览、共同编辑器、确认与隐私遮罩。遮罩会移除财务DOM，而非仅模糊数字。

## 通知来源与操作

通知直接显示于首页，顶部铃铛显示所选月份的未读数量并定位通知区域。支持全部/未读筛选、单条/全部已读、展开更多、详情及关联记录跳转。切换月份先移除旧范围通知；进入来源页前重新加载实际状态，避免后台新增记录后跳转到旧缓存。

| 通知 | 触发依据 | 点击后 |
|---|---|---|
| 预算超额 | 本月规划币种中，已确认费用（扣除关联退款）超过用户批准的类别预算 | 查看实际费用/预算/超额金额，定位对应类别的有效费用记录 |
| 工资已记账 | 已确认、未冲正的`income`，类别明确为Salary/Wages/工资/薪资/薪酬 | 查看原币种金额与来源，定位单笔账本记录；不等于已核实银行到账 |
| 记录价格下跌 | 股票/ETF/基金最近两个不同时间的已保存单位价格；最新观察属于所选月份，旧价格大于0、新价格较低 | 查看两次价格和日期，定位投资历史；缺价、单点、市值下降或已归档条目不触发 |

价格提醒比较用户保存的单位价格，未调整公司行动、汇率或费用，不代表实时行情、总投资收益或交易建议。相同观察时刻以最新修订替换，不把修订重复当作新时点。金额使用Decimal/BigInt，价格比较保留最多8位小数，展示比例舍入到两位。

当前均为**站内通知**。本地/云端在首页可见时每45秒检查保存记录，重新聚焦页面或手动刷新也会检查；隐藏、锁定、隐私遮罩或撤回分析用途时停止检查。撤回分析后清除通知及衍生视图。不会请求系统推送权限、发送邮件，或自行拉取银行/股票数据。银行与行情接入后仍需另行配置授权、来源和时效。

Demo保持离线，由合成记录与手动价格观察产生相同交互，不访问正式API。新场景包含预算、工资、价格三类；已有浏览器场景如缺少新增价格示例，可使用“Demo scenario & reset → Reset demo”重新加载预设，现有演示修改不会自动覆盖。

## 数据与接口

无需新增数据库迁移。正式通知按当前账本、规划、价格与授权即时生成；只把最近500个已读标识保存在当前用户的`settings.notification_receipts`。一次最多返回50条。标记已读不修改金额、账本版本、规划版本或确认令牌；重复标记不会重复产生财务影响。

| 接口 | 契约 |
|---|---|
| `GET /api/notifications?period=YYYY-MM` | 登录后返回当前空间、指定月份的通知，含来源、期间、币种、版本、生成时间及`analysis_authorized`；无数据为空，不补演示信息 |
| `POST /api/notifications/read` | `{ "period": "2026-09", "ids": ["current-notification-id"] }`；最多50个当前通知ID，需同源与登录，拒绝其他空间或已变化的通知 |
| `GET /api/state` | 同一快照中附带`notifications`，已有业务更新后同步首页 |

Next.js同源代理、Python身份/用途检查和云端RLS继续生效。通知计算与已读记录仅在本人空间，未新增营销追踪或外部资料传输。导出包含正式版已读设置；完整删除清除设置。Demo标识保存在独立Demo浏览器空间，并可导出/清除。迁移至新云空间重新建立通知及已读状态，不继承旧权限。

## 2026-10-16 布局对齐补充

所有模块使用同一顶部控件网格：月份、币种和同行操作均为44px，月份说明不参与其他控件的垂直居中。窄容器将操作按钮移至下行并填满；原有手机快捷操作的显示规则保持。

设置偏好占满整行，四项服务状态使用可换行且末行自动扩展的布局。首页指标自动换行并填满；关系卡、投资卡和设置双列区域的末张卡补齐整行，不通过调整DOM顺序填洞，阅读和键盘顺序保持一致。

投资分布改为横向概览，历史卡使用下方完整宽度。同排投资卡通过子网格对齐标题、操作栏和分析区；单点时间筛选保持位置但禁用，明确资料不足。图表高度限制在140–240px，避免独占一行时随卡片宽度产生过高空白。图表与单点说明共享显示区，来源入口在同排卡片底部对齐。

本轮只修改共用视觉样式和投资卡展示结构；正式API、通知规则、账本确认及用户数据存储不变。证据与截图见[最新布局验收](UX_VALIDATION.md)。
