# 2026-10-15 网页审查修复

依据用户指定的 `finagent-web-audit-2026-10-15/REVIEW.md`。本轮修改项目代码，原审查报告保持原始证据。财务测试使用临时合成账本；未访问用户私人数据库，也未改动3001来源已有的演示记录。

| 编号 | 修改与验证 |
|---|---|
| F01 | 正式/Demo 分析请求带 `currency`；结果自带期间、币种、版本、来源事件。切换时过滤旧结果，序列与会话失效保护防止迟到响应覆盖；无证据降级。浏览器覆盖 AUD/CNY/USD、刷新和迟到响应 |
| F02 | KPI 使用 `Monthly surplus`，保留收入减费用定义；月度对照使用 `Expenses`。现金变化仍独立，原本金/退款/转账回归保留 |
| F03 | 区分自然日与工作日+用户声明休市日；接受周末/休市间隔，明确报告真正缺数日期、重复和非法价格。展示来源、频率、窗口、观察数和复权状态；不内置完整交易所假日日历，不补造价格 |
| F04 | 单笔、批量、Agent 最终预览包含匹配记录及原因；必须勾选独立交易并填写5–500字原因。后端和 Demo 均校验，账本变化使旧预览失效；原因写入来源证据，提交重试另由幂等回执控制 |
| F05 | 修复深色分析标题旧紫色，补齐分类折叠项颜色；八模块纯色文本测量与200% CSS缩放回归。渐变、SVG/PDF另外目视检查；没有据此声称整站无障碍认证 |
| F06 | 解释意图与执行请求分开；`Explain why an internal transfer... Do not execute...` 可回答；追加实际转账命令仍阻断。分析工具仍只读 |
| F07 | 手机主要导航复用可见/无障碍标签；More 的名称包含可见文字。320px检查标签、点击和主操作可达性，Transactions 保持完整一行 |
| F08 | URL 仅保存 `tab/period/currency` 白名单；刷新、深链接、前进后退恢复工作位置。金融问题、金额和账户名称不进入 URL |
| F09 | 交易先新增/导入及审核页签，统计折叠；预算/目标先实际规划，长期模拟折叠；分析输入在首屏，无需展开依据 |
| F10 | View basis 直接展开、聚焦并滚动到依据，显示范围、生成时间、快照和计算/账本版本 |
| F11 | 总览流水按发生日期倒序，创建时间/稳定ID作为次级排序 |
| F12 | 金额错误关联编辑字段，取消/关闭/跨页清除，不再留到 Portfolio；删除重复错误呈现 |
| F13 | 全局入口改为 `Go to module… / 跳转模块`，与实际模块检索范围一致 |
| F14 | 禁用开发指示器；验收使用生产构建，移动导航不受 Next N 按钮遮挡 |
| F15 | 单点投资显示观察值、日期、依据和补第二次观察提示；没有趋势 SVG 和范围切换器。收益依据选择仍保留 |
| F16 | 未编辑工作表以精确当前金额作为目标，全部差额为零；用户编辑后才执行权重校验与最小单位舍入 |
| F17 | 产品统一知账/ZhiZhang，FinAgent为助手；演示类别、地区、单位和月份说明按语言显示；模型/检索技术选项收纳到高级设置 |
