## 当前可运行交付

| 运行模式 | 入口 | 数据与能力 |
|---|---|---|
| 本地版 | `npm run dev` | 保留 Python/SQLite、访问码、本机 OCR、完整已有业务 |
| 离线 Demo | `npm run demo` | 原浏览器合成预设，无 API/外网依赖 |
| 云端开发/受邀验证 | `npm run cloud` | 真实 API、托管身份适配、PostgreSQL/RLS；依赖用户配置的 Supabase 项目；无预设金融记录 |

云端使用独立 `.next-cloud` 构建目录、FastAPI/Uvicorn 和专用 PostgreSQL 运行角色。Next.js SSR Cookie、PKCE恢复、TOTP、设备撤销、邀请准入、每事务身份复核、数据库复合键/精确分录约束、本地 JSON 原子迁移、私人规则/反馈、隔离文件接收、独立删除签名记录及离线恢复围栏已有代码。分录/确认/计算领域逻辑与原版复用。

部署、配置和免费限制见 [CLOUD_RUNNING](CLOUD_RUNNING.md)，架构决策见 [ADR004](adr/004-free-first-cloud-staging.md)。本轮未创建供应商账号、未连接用户真实数据、未部署或开通收费。
